# BeyoSticker assets

All four active categories use the supplied final photos. Replace these PNG files without changing the layout:

- `dist/assets/catalog/builder-01.png`, `builder-02.png`
- `dist/assets/catalog/dino-01.png`, `dino-02.png`
- `dist/assets/catalog/flower-01.png`, `flower-02.png`
- `dist/assets/catalog/princess-01.png`, `princess-02.png`

Update the corresponding English alt text in `dist/index.html` if the photo content changes. Gallery images come automatically from those same paths. Thumbnails are square and enlarged photos preserve their original proportions.

The hero uses the independent `dist/assets/brand/hero.png`. The header and footer use `logo.png` in that folder. The favicon is `favicon.svg`.

Coming Soon cards use category emojis. They have no product photos, prices, or active product-order buttons.

Pack options: Regular 64 ($9.99), Large 128 ($17.99, Save 10%), Super 256 ($26.99, Best Value · Save 32.5%), USD. Shipping is separate. Pack choices update the price and WhatsApp message. No checkout or payment system is included.

Every pack contains 16 different designs. Savings compare Large/Super prices with the equivalent number of Regular packs, rounded as displayed.
